# Website editing instructions

Read and follow [CLAUDE.md](CLAUDE.md) before editing this website. It contains the project workflow, design rules, deployment instructions, and clean-link policy.

Never introduce `utm_source=chatgpt.com`, other `utm_*` parameters, or similar campaign, referral, affiliate, or AI-attribution tracking tags into the website or its downloads. Use clean destination URLs and preserve functional parameters such as paper IDs, search queries, download options, and content-version hashes. Check final URLs before committing link changes.
